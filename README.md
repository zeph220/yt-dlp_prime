Téléchargez yt-dlp.exe, ffmpeg.exe, ffmplay.exe et ffmprobe.exe depuis la page releases, et lancer.bat.
Placez-les dans un dossier.
Double-cliquez sur lancer.bat puis entrez l'url de votre playlist YouTube. 
Tous les titres seront automatiquement téléchargés dans un dossier portant le nom de la playlist.
