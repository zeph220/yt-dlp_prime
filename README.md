Ceci est une version améliorée et plus facile à utiliser du logiciel bien connu yt-dlp

Téléchargez yt-dlp.exe, ffmpeg.exe, ffmplay.exe et ffmprobe.exe depuis la page [releases](https://github.com/zeph220/yt-dlp_prime/releases/tag/main)
[], et lancer.bat.Placez-les dans un dossier.

Double-cliquez sur lancer.bat puis entrez l'url de votre playlist YouTube. 

Tous les titres seront automatiquement téléchargés dans un dossier portant le nom de la playlist. 

Ils inclueront le titre, l'artiste, la pochette et d'autres métadonnées.
